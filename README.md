# MOA — 목표 자산 모으기 (공개 배포판)

카드 이용내역 엑셀을 올리면 카테고리별 지출·월 예산·자산·저축 플랜을 한 화면에서 보여주는 가계부.
서버가 없는 정적 웹페이지입니다. 사용자의 데이터는 각자 브라우저(localStorage)에만 저장되고 어디로도 전송되지 않습니다.

## 폴더 구성

- `index.html` — 앱 전체 (HTML+CSS+JS 단일 파일)
- `xlsx.full.min.js` — 엑셀 파서(SheetJS 0.18.5). `index.html`과 같은 폴더에 있어야 함
- `README.md` — 이 문서

## GitHub Pages에 올리기 (5분, git 설치 불필요)

1. https://github.com 로그인 → 오른쪽 위 **+** → **New repository**
   - Repository name: `moa` (원하는 이름)
   - **Public** 선택 → **Create repository**
2. 만들어진 저장소 화면에서 **uploading an existing file** 링크 클릭
   → `index.html`, `xlsx.full.min.js` 두 파일을 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings** 탭 → 왼쪽 **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
4. 1~2분 뒤 같은 화면 상단에 주소가 뜹니다: `https://<아이디>.github.io/moa/`
   이 링크를 외부 사람에게 공유하면 됩니다.

파일을 고쳐서 다시 올리면(같은 이름으로 업로드 → Commit) 1~2분 내 반영됩니다.

## 사용자 안내(공유 시 함께 보내면 좋은 문구)

- 처음 열면 4단계 입력(목표·월급 → 고정 저축 → 자산 → 카드 내역). 자산·카드는 건너뛰고 나중에 넣어도 됩니다.
- 월급은 세전만 넣으면 4대보험·소득세를 추정합니다(중소기업 취업자 감면 선택 가능). 급여명센서의 실수령을 직접 넣는 것이 가장 정확합니다.
- 카드 파일: 우리카드 이용대금명세서(.xls), 신한카드 이용내역(.xlsx)은 자동 인식. 다른 카드사는 처음 한 번 “날짜·가맹점·금액 열”을 지정하면 다음부터 자동.
- 데이터는 이 브라우저에만 저장됩니다. 기기 변경·브라우저 초기화 전에 **업로드·설정 → JSON 내보내기**로 백업하세요.
- 예시 데이터로 먼저 둘러볼 수 있습니다(온보딩 화면의 버튼).

## 지원 형식·한계

- 자동 인식: 우리카드 이용대금명세서 상세내역(.xls, 체크+신용 혼재, 연도 없음 → 현재 연도 기준 역산), 신한카드 이용내역(.xlsx)
- 그 외 .xls/.xlsx/.csv: 열 매핑 화면으로 처리. 매핑은 헤더 서명 기준으로 기억됨
- 네이버페이·카카오페이·계좌이체·현금은 파일이 없으므로 포함되지 않음
- 소득세 추정은 간이세액표 산식을 단순화한 근사치(±10% 수준)
- 자산 스크린샷 OCR은 지원하지 않음(직접 입력)

## 은조 개인욨(사내 아티팩트)과의 관계

- 사내 아티팩트 버전(서버 저장, 회사 계정 전용)과 데이터 스키마가 같아서, 아티팩트에서 **JSON 내보내기** → 이 사이트에서 **JSON 가져오기**로 옮길 수 있습니다.
- 카테고리 규칙(`core` 부분)은 두 버전이 공유합니다. 규칙을 고치면 두 파일 모두 갱신하세요.
